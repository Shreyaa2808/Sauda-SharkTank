# Shark Tank India DBMS — Remaining Phase C Deliverables

This bundle contains Phase C Steps 2–5. Phase C Step 1 (`phase-c-step-1-entity-inventory.md`) is already a separate document. Review and approve the documents in order; they are coordinated proposals and should be copied into the repository only after review.

1. `phase-c-step-2-attribute-relationship-refinement.md` — refines entities, attributes, cardinalities and constraints.
2. `phase-c-step-3-er-model-and-diagram.md` — gives the conceptual ER model and Mermaid diagram source.
3. `phase-c-step-4-relational-mapping.md` — maps the ER model to relations and identifies PKs, FKs, AKs and constraints without SQL DDL.
4. `phase-c-step-5-normalization-and-design-review.md` — documents 1NF/2NF/3NF reasoning, functional dependencies, anomaly prevention and validation checks.
5. `phase-c-design-decision-log.md` — consolidated design decisions and enforcement items reserved for Phase D.

**Boundary:** This bundle ends Phase C design. It does not create MySQL DDL, indexes, seed data or application code; those belong to Phase D.
